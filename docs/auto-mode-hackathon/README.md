# Auto Mode для Kilo CLI — рабочая память

Эта папка — общий контекст проекта безопасного автономного режима для хакатона. Она должна позволять новому агенту продолжить работу без повторного исследования репозитория.

## Scope

- Только CLI и backend из `packages/opencode/`.
- Низкоуровневый sandbox из `packages/kilo-sandbox/` входит в scope, потому что CLI его использует.
- VS Code, JetBrains, Agent Manager и другие клиенты не входят в scope.
- Цель — демонстрационный контур для хакатона, а не немедленная production-реализация всех заявленных гарантий.

Исследование текущего состояния выполнено на commit `b391948e61` ветки `main`, 5 сентября 2026 года.

## Правила ведения памяти

- Не записывать предположение как факт. Помечать его как `Гипотеза` или `Нужно проверить`.
- Для технических утверждений указывать символ и путь к исходному файлу.
- После реализации части ТЗ добавлять отчёт в `implementation/`, а в соответствующем файле `specs/` менять статус.
- Не переписывать историю решений молча. Существенное изменение фиксировать в `notes/decisions.md`.
- Не складывать сюда бинарные сборки, логи большого размера и временные файлы.
