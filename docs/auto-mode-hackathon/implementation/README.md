# Артефакты реализации

Здесь хранятся короткие отчёты по выполненным частям ТЗ.

Имя файла: `AM-NN-<slug>.md`.

Минимальный формат отчёта:

```text
# AM-NN — название

Статус: complete | partial | blocked
Commit/ветка:

## Что сделано
## Фактическая архитектура
## Изменённые файлы
## Проверки и результаты
## Отклонения от ТЗ
## Известные ограничения
## Handoff следующему агенту
```

Исходные логи тестов сюда не копировать. Указывать команды и краткий результат.
